Datenschutzhinweis „Dokumentenablage“

Die Dokumentenablage ist eine private Anwendung, die ausschließlich vom Betreiber selbst für das eigene Gmail-Postfach und das eigene OneDrive genutzt wird. Es gibt keine weiteren Nutzer.

Welche Daten verarbeitet werden

  • Gmail: E-Mails und Anhänge werden gelesen, um wichtige Dokumente zu erkennen. Bearbeitete Mails bekommen ein Label. Es werden keine Mails gelöscht oder versendet, außer einer wöchentlichen Übersicht an das eigene Postfach.
  • OneDrive: Dokumente werden im Ordner „Ablage“ gespeichert, umbenannt und in Unterordner sortiert.
  • Auslesen: Zum Erkennen von Datum, Absender und Inhalt werden Dokumente an die Claude-API von Anthropic übermittelt. Sie werden dort nicht zum Training verwendet.

Speicherung

Zugangsdaten werden verschlüsselt in einem privaten GitHub-Repository gespeichert. Die Dokumente selbst liegen nur im eigenen OneDrive. Eine Weitergabe an Dritte findet nicht statt.

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions bzw. account.live.com/consent/Manage entzogen werden.
