# Dokumente – iPhone-App

Web-App für die Dokumentenablage: offene Rechnungen abhaken, unklare Dokumente zuordnen, scannen, suchen, Status.
Läuft über GitHub Pages; Anmeldung mit dem eigenen Google-Konto, die Daten liegen nur in Google Drive.
Hier liegen keine Daten oder Schlüssel. Der eigentliche Ablage-Code ist im privaten Repository `dokumentenablage`.
